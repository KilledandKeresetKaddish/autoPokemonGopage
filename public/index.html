本月 Weekly Rotations

本期优先级（7/6）

今天起进入传奇之路，短期团战资源优先给 7/10 起源双龙与原始双神、7/11–7/12 GO Fest 超级超梦 X/Y；月中后请提前预留一波团战券给 7/22 索尔迦雷欧闪光首发。

今天开始做

  • 7/6 传奇之路首日是全世代传说池与超级暴飞龙，目标很多但池子分散，建议只补关键缺口或顺手打高价值个体。
  • 7/7–7/9 重点关注酋雷姆形态、奈克洛兹玛形态、王者苍响/藏玛然特；准备龙、妖精、恶、幽灵、地面等队伍轮换。
  • Max 侧今天为极巨化吉利蛋，投入优先级低于本周传说与超级团战。

本周资源分配

  • 7/10 起源帝牙卢卡、起源帕路奇亚、原始盖欧卡、原始固拉多价值最高，适合把主要团战券与远程票集中到这天。
  • 7/11–7/12 GO Fest 全球紧接登场，超级超梦 X/Y 分日出现；若想拿能量与高 IV，务必预留复活、药水与背包空间。
  • 7/13–7/14 三神鸟与超级路卡利欧短暂返场，除非缺图鉴、闪光或超级能量，否则优先级低于 GO Fest 与 7/22 新闪。

7/22 新闪重点

  • 7/22–7/28 索尔迦雷欧进入 5★ 团战，本轮首度开放闪光；7/22 18:00–19:00 团战时刻是最适合集中刷的一小时。
  • 同周超级暴飞龙在超级团战轮换，龙/飞属性糖果加成与打手价值都高，可顺手补超级能量。
  • 若团战券有限，建议在 GO Fest 后保留一部分给索尔迦雷欧，而不是全部投入 7/15–7/21 的盖欧卡常规轮换。

练哪类攻手

  • 短期传奇之路：龙、妖精、恶、幽灵、地面最常用；岩石、电、冰也能覆盖飞行系与部分龙系弱点。
  • 7/10 与 GO Fest：草/电应对盖欧卡，水/地面应对固拉多，恶/幽灵应对超能力与幽灵目标，妖精/飞行可对超级超梦 X 有用。
  • 7/22 索尔迦雷欧为超能力/钢，优先准备火、地面、幽灵、恶系主力；详细克制仍以「当前团战 Counter」为准。

超级进化参考

选择一只宝可梦,填入它已超级进化的次数,规划器会动态比较三条升级路线:免费等满休息期(7 / 5 / 3 天)、每天付费进化一次、花能量立即升级。下方附静态查询表(各等级消耗、通用加成、立即升级价目)与 Bulbapedia 来源链接。所有费用与时长均由「首次消耗(Initial Cost)」推算——新超级进化公布时,只需在 data/mega.json 里加一行(名称 + 首次消耗,可达超级最高的再标 superMax),其余自动生成。

世界时钟 · 时段筛选

默认按「最早 → 最晚」列出各时区代表地。选择时段则筛选此刻当地处于该时段的地区;「结束」为上界且不含本身(如 14 → 17 = 14:00–17:00),可选到 24:00(当日结束);跨午夜把「结束」设得比「起始」小(如 22 → 02)。

→
24 小时时间轴

列表覆盖 UTC+14 → −12 的全部时区,每档列出代表地点(同一时区可能多地并列);精选地点为社区常用 PoGo 热点,坐标可点击跳转地图。各地时间按所在时区实时计算(含夏令时),仅供参考。
